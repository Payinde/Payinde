## 🔐 Featured Cybersecurity Project

### 🛡️ Build a SOC Lab with Wazuh

Built and documented a hands-on Security Operations Center lab using Wazuh, progressing from traditional SIEM monitoring and incident investigation to an independently developed human-in-the-loop AI-assisted SOC triage workflow.

**Key areas demonstrated:**
- Wazuh SIEM deployment and administration
- Windows and Linux endpoint telemetry
- Sysmon integration
- Custom SOC dashboards
- File Integrity Monitoring (FIM)
- Custom detection rules
- Active Response
- Incident investigation
- MITRE ATT&CK mapping
- Python policy and validation controls
- Local AI triage using Ollama and Qwen 2.5
